# Кто какой заказ берёт

Под каждым сообщением бота две кнопки: **✅ Беру** и **🚫 Не беру**. Нажатие записывается в базу
(кто, что, когда). Повторное нажатие той же кнопки снимает отметку. Отмечать могут только получатели из
`notifications.telegram` (`chat_id`, `chat_ids`, `TELEGRAM_CHAT_IDS`).

Страница со списком показывает отправленные лиды, свежие сверху, и отметки всех получателей. Фильтры:
«Все», «Свободные», «Взятые».

## Включение

```yaml
notifications:
  telegram:
    claim_buttons: true
web:
  host: 127.0.0.1
  port: 8080
```

В `.env`: `LEAD_WEB_TOKEN=<случайная строка не короче 16 символов>`. Запуск (держит и страницу, и приём нажатий):

```bash
lead-parser web --config config.yaml
```

Страница открывается по ссылке `http://host:8080/?key=<токен>`; ключ запоминается в cookie. Без ключа — 401.

## Важно

* Кнопки работают только пока запущена команда `web`: она принимает нажатия через getUpdates
  (webhook не нужен). Поэтому не запускайте второй процесс с getUpdates на том же боте.
* Страница отдаётся по http без шифрования. Наружу открывайте только за прокси с TLS или через ssh-туннель:
  `ssh -L 8080:127.0.0.1:8080 server`.
* Страница только читает базу, ничего не меняет.
