# Кто какой заказ берёт

Под каждым сообщением бота две кнопки: **✅ Беру** и **🚫 Не беру**. Нажатие записывается в базу
(кто, что, когда). Повторное нажатие той же кнопки снимает отметку. Отмечать могут только получатели из
`notifications.telegram` (`chat_id`, `chat_ids`, `TELEGRAM_CHAT_IDS`).

Страница со списком показывает отправленные лиды, свежие сверху, и отметки всех получателей. Фильтры:
«Все», «Свободные», «Взятые».

## Включение

```yaml
notifications:
  telegram:
    claim_buttons: true
web:
  host: 127.0.0.1
  port: 8080
```

В `.env`: `LEAD_WEB_TOKEN=<случайная строка не короче 16 символов>`. Запуск (держит и страницу, и приём нажатий):

```bash
lead-parser web --config config.yaml
```

Страница открывается по ссылке `http://host:8080/?key=<токен>`; ключ запоминается в cookie. Без ключа — 401.

## Важно

* Кнопки работают только пока запущена команда `web`: она принимает нажатия через getUpdates
  (webhook не нужен). Поэтому не запускайте второй процесс с getUpdates на том же боте.
* Страница отдаётся по http без шифрования. Наружу открывайте только за прокси с TLS или через ssh-туннель:
  `ssh -L 8080:127.0.0.1:8080 server`.
* Страница только читает базу, ничего не меняет.

## Переходы по ссылке (трекер)

С `notifications.telegram.track_clicks: true` в сообщении каждому получателю уходит его личная ссылка
`<web.public_url>/r/<токен>` вместо настоящей. Токен уникален для пары «заказ + получатель» и не
подбирается (HMAC от `web.token`). Переход фиксируется (первый раз, последний, сколько раз) и сразу
перенаправляет на заказ. Настоящий адрес заказа получатель не видит в сообщении.

```yaml
notifications:
  telegram:
    track_clicks: true
    names: {"566482716": "Иван"}      # необязательно: имена вместо id на странице
web:
  host: 0.0.0.0
  port: 8080
  public_url: http://IP:8080          # адрес, по которому получатели открывают ссылку
```

На странице у каждого заказа видно, кто перешёл (👁 время), а кто нет (○), вкладка «Не открыты» показывает
заказы, которые открыли не все получатели.

Ограничения: боты предпросмотра (TelegramBot, curl и подобные) не считаются. «Перешёл» означает, что
ссылка открыта; было ли дальше действие на Профи, трекер не видит. В таблицу Sheets уходит настоящая
ссылка, а не личная.
